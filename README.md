# C# Exercises

My solutions to C# / .NET coding exercises, organised as one console project per exercise inside a single solution.

## Tech

- .NET 10
- C# 14

## How to run

```bash
git clone https://github.com/Feba8199/csharp-exercises.git
cd csharp-exercises
dotnet run --project 01-DogClass
```

Build everything at once:

```bash
dotnet build
```
